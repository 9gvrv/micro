# Micro Landing Page

Standalone single-page site for Micro, the AI prototyping agent. It presents the idea-to-app workflow and links to the repository.

## Run

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite.

## Scripts

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Start the development server. |
| `pnpm build` | Type-check and build for production. |
| `pnpm preview` | Preview the production build locally. |

## Scope

One page, no routing, backend, authentication, or interactive demo. The only external link is the Micro GitHub repository.
