## Conventions

- `Project`: directory name under `generated/`.
- `Template`: `minimal-react`, `dashboard`, or `custom`.
- `Created`: ISO date (`YYYY-MM-DD`).
- `Status`: `verified`, `needs-fix`, or `abandoned`.
- `Path`: repository-relative path.
- `Preview`: local URL used during verification; note if it is no longer running.
- `Notes`: one short line about scope or status.
